## Hey

I focus on learning cybersecurity through hands-on practice—CTFs, labs, and controlled exploitation environments. I prefer understanding how things break rather than just reading theory.

---

## Current Focus
- Web exploitation (SQL injection, auth bypass, command injection)  
- Binary exploitation (buffer overflows, PIE bypass)  
- Linux privilege escalation (SUID, enumeration)  
- Recon and manual service analysis  

---

## Experience (CTFs & Labs)

### Web
- Session hijacking via exposed tokens  
- Cookie/header-based authentication bypass  
- Command injection through unsafe inputs  
- Rate-limit bypass using header manipulation  
- IDOR and misconfiguration testing  

### Binary
- Stack buffer overflows → control flow redirection  
- PIE bypass using leaked addresses  
- SUID binary exploitation under constraints  

### Crypto / Encoding
- Diffie-Hellman key recovery and XOR decryption  
- Base64, ROT13, and custom encoding challenges  

### Systems / Network
- SMB enumeration and file extraction  
- Memory dump analysis (/heapdump)  
- ZIP recovery and password cracking  

### Other
- Git commit forgery to trigger server hooks  
- Byte-precise input crafting for validation bypass  
- Cookie brute-force enumeration
